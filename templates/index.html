User Manual

1. Network Tests (What we check)

  • Loopback (127.0.0.1): Verifies your network card driver is working. Failure indicates a hardware/driver issue.
  • Gateway: Checks connection to your local router. Failure means you are disconnected from your local network.
  • ISP DNS (DNS 1): Connection to your Internet Service Provider's DNS server.
  • Hinet DNS (DNS 2): Connection to Taiwan's primary DNS (High stability reference).
  • Google DNS (DNS 3): Connection to Google Public DNS (8.8.8.8). verifies global internet access.
  • DNS Resolution: Tries to translate a domain name (e.g., www.google.com) to an IP address. If this fails while Pings work, your DNS configuration is broken.

2. Configuration Parameters

  • Check Interval: The waiting time (in seconds) between each health check cycle.
  • Panic Mode Duration: If a failure is detected, the system switches to "Panic Mode" and checks rapidly (every 1 second) for this duration to capture instability details.
  • Ping Frequency: Controls how often we send active Ping packets.
    • Set to 1: Ping every check cycle (Most accurate).
    • Set to 3: Ping only every 3rd cycle (Reduces network traffic).

3. Status Indicators

  • OK: The check passed and connection is stable.
  • FAIL: The check failed. System enters Panic Mode.
  • Waiting...: No data received yet.
